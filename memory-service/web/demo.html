这个演示对应 AURORA-CAIR 的哪些创新点？

  • 嵌套前缀量化与可靠区间：每条向量存 16-bit 完整编码，4/8/16-bit 精度取同一编码前缀，区间天然嵌套；语义分数由区间算术得到上下界。
  • 安全剪枝与精确认证：上界低于第 K 大下界的候选不可能进入 Top-K；Top-K 成员下界严格高于外部上界时认证通过，再精确恢复内部顺序。
  • CARS 自适应恢复：在单条恢复、块级恢复、多精度细化之间按收益/成本选择，无收益时安全回退到全量精排；轨迹记录动作与读取字节。
  • 分层存储：SQLite 保存元数据与压缩码，vectors.bin 按 16 条/块保存精确 float32 向量，块缓存计入 I/O 统计。
  • 可维护性：新增先写精确向量再发布索引；修正生成新版本并取代旧版本；删除先不可检索再释放槽位；当前/历史查询使用不同版本集合。
  • Memora 记忆语义：事件时间与有效时间分离；普通主题提及只记录本轮激活，不修改长期权重；明确确认/修正才更新状态并留版本。

注意：默认嵌入是确定性的字符 n-gram 哈希模型（离线可运行），不是语义大模型；Top-K 精确性是对“本服务定义的评分函数”而言的精确，不代表语义检索质量。
